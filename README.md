# Менің алғашқы жобам 

## Жоба туралы

Бұл — менің GitHub-тағы алғашқы жобам. Бұл жобаны бағдарламалау дағдыларымды дамыту үшін жасап жатырмын.

## Мақсаты

* Жаңа нәрселерді үйрену
* Код жазуды меңгеру
* GitHub-пен жұмыс істеуді үйрену

## Қолданылатын технологиялар

* HTML
* CSS
* JavaScript

## Автор

Менің алғашқы жобам!
